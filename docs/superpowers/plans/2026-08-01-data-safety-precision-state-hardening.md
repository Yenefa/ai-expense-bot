# Data Safety, Precision, and State Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Protect the stored LLM API Key, apply each LLM mutation batch atomically, keep persisted money exact in integer cents, and restore navigation state after Activity recreation without reducing OCR capability.

**Architecture:** Use direct Android Keystore AES-256/GCM encryption behind a small storage interface, with one-time migration from the legacy DataStore field and explicit backup exclusions. Move parsed monetary values to integer cents before they reach repositories, isolate LLM writes behind a Room transaction runner, and make the existing screen identifiers saveable enums. Preserve the current UI, Room schema, OCR implementation, bundled Chinese model, and universal APK ABI coverage.

**Tech Stack:** Android API 26-34, Kotlin, Android Keystore, AES/GCM/NoPadding, DataStore, SharedPreferences ciphertext storage, Room transactions, kotlinx.serialization JSON, Jetpack Compose state saving, Gradle and PowerShell contracts

## Official design basis

- Android Keystore keeps key material non-exportable and recommends avoiding Keystore work on the main thread: `https://developer.android.com/privacy-and-security/keystore`.
- Android documents AES/GCM/NoPadding with Keystore-generated randomized IVs: `https://developer.android.com/reference/android/security/keystore/KeyGenParameterSpec`.
- `EncryptedSharedPreferences` and its master-key APIs are deprecated in favor of direct platform APIs and Android Keystore: `https://developer.android.com/reference/androidx/security/crypto/EncryptedSharedPreferences`.
- Android requires `fullBackupContent` rules for Android 11 and lower and `dataExtractionRules` for Android 12+; SharedPreferences and internal files are included by default unless excluded: `https://developer.android.com/identity/data/autobackup`.
