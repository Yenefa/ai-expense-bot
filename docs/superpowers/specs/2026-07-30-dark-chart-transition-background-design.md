# v3.6 深色图表与页面过渡背景修复设计

## 问题

深色模式下存在两处视觉问题：

1. 支出分析中的柱形图和折线图沿用图表库默认配色，坐标文字、轴线和网格线接近黑色，与 `#1C1C1E` 背景对比不足。
2. 主页面横向切换时，页面之间露出的动画容器根背景仍为白色。浅色模式不明显，深色模式会看到白色页面跟随滑动。

现有页面切换动画代码仍然存在，本次不更换导航结构，也不改变动画方向和时长。

## 方案

### 页面过渡背景

在 `MainActivity` 的页面动画层外增加一个占满窗口的主题背景容器：

- 浅色模式使用 `AppColors.Bg` 的白色。
- 深色模式使用 `AppColors.Bg` 的深色。
- `AnimatedContent` 和所有覆盖式子页面继续使用现有滑入、滑出与淡入淡出参数。

这样页面滑动期间即使露出底层，也只会看到当前主题对应的背景，不再出现深色页面后跟随白底。

### 图表深色配色

为柱形图和折线图显式提供当前应用主题对应的图表组件颜色，不依赖图表库默认值：

- 坐标文字：使用 `AppColors.TextSecondary`，保证可读性。
- 轴线和刻度线：使用弱化后的 `AppColors.TextMuted`。
- 网格线：使用低透明度的 `AppColors.TextMuted`，可见但不抢数据主体。
- 柱形和折线数据：使用主题前景色或强调色，保持深浅模式均有足够对比。

浅色模式继续保持白底与深色文字，不改变页面布局、数据和图表尺寸。

## 范围

涉及：

- `MainActivity.kt`
- `BarChartView.kt`
- `LineChartView.kt`
- 必要的主题或图表组件辅助代码
- 对应的主题配色测试

不涉及：

- 导航架构重写
- 页面动画方向、速度调整
- 图表数据计算修改
- CSV 导入功能修改
- 启动图标修改

## 验证

1. 单元测试验证深浅主题下图表使用不同且有足够对比度的颜色。
2. 构建 Debug APK，确认 Kotlin/Compose/Vico API 编译通过。
3. 检查 APK 版本仍为 v3.6、包名和签名与上一版一致。
4. 设备验证时检查：
   - 深色图表坐标文字和网格线清晰可辨。
   - Chat、分析、历史、设置之间横向切换时不再露出白底。
   - 浅色模式显示和动画保持原有效果。
