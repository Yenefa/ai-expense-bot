# 启动图标安全区修正设计

## 问题

当前启动图标把完整原图铺满 108×108 自适应图标画布。Android 桌面遮罩和 Android 12+ 系统启动画面只稳定显示中央区域，因此笔记本外框被大量裁切。

## 目标

- 桌面图标和系统启动画面都显示完整的紫色笔记本图片。
- 优先保证圆形、圆角方形等不同系统遮罩下不裁切。
- 不修改应用内界面、功能、包名或版本号。

## 方案

继续使用现有自适应图标结构。将原始正方形图片等比缩小到 108×108 画布边长的 43%，居中绘制；剩余区域填充深紫色 `#2B1A3B`。

Android 的稳定安全区直径为画布的约三分之二。正方形要完整落入该圆形区域，其边长需不大于圆直径除以 `√2`，约为画布的 43.2%。采用 43% 可保留少量余量。

## 验证

- 生成五档密度 PNG：108、162、216、324、432 像素。
- 验证原图区域居中，边长为各画布的 43%。
- 预览缩放后的前景资源。
- 运行单元测试并构建 Debug APK。
- 验证 APK 包信息、启动图标资源、签名和 SHA-256。
- 成品输出到 `C:\Users\fuker\Desktop\app\codex change`。
