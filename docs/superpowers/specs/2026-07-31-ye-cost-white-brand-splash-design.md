# Y.E cost 纯白品牌开屏设计

## 目标

- 应用品牌名统一为 `Y.E cost`。
- 开屏显示 slogan：`记下日常，看见生活`。
- 背景使用纯白 `#FFFFFF`，紫色仅保留在 Logo 图稿中。
- 消除当前启动图中央位图的四个黑角。
- 保持版本 `3.6` / `versionCode 27`，不改业务数据和页面逻辑。

## 视觉设计

系统 SplashScreen 使用纯白背景和透明占位图标，避免系统直接绘制带黑角的原始前景图。主 Activity 首帧绘制同样纯白的品牌页：中央 Logo 通过固定圆角容器裁切，并放大约 1.42 倍以裁掉前景资源自带的安全区与黑色角；下方依次显示近黑色 `Y.E cost` 和中性灰 slogan。

配色：

- 背景：`#FFFFFF`
- 品牌名：`#211D24`
- slogan：`#77717A`
- 紫色：仅来自现有 Logo，不增加紫色背景、渐变或装饰。

## 启动过渡

品牌页覆盖现有首页约 850 毫秒，再用 220 毫秒淡出。系统开屏与品牌页背景完全一致，因此切换时不闪白、不闪紫；不新增独立 Activity，也不影响现有页面左右滑动动画。

## 品牌统一

Android 桌面应用名、顶部栏、关于页、说明书、聊天占位文案、LLM 身份提示及 README 中的旧名称统一替换为 `Y.E cost`。包名 `com.expense.tracker` 保持不变，保证升级与本地数据兼容。
