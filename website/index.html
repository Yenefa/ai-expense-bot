这一版更新了什么

  • 深度修复（推荐升级）：修复跨年历史页崩溃、周期账单跳月/31 号漂移与并发重复、未来日期误计入本月、提醒设置被默认值覆盖等问题（v3.14.1）。
  • 主动提醒更聪明：总消费正常时，单一分类异常也会提醒；提醒中心新增未读角标，打开 App 也会自动检查一次（v3.14.0）。
  • 显示修复：预算管理 / 设置 / 数据导出 / 周期账单页在部分机型内容超出屏幕时可正常滚动，不再截断（v3.13.1–v3.13.2）。
  • 对话记账更稳：连续追加（「还有一杯奶茶16」）不会把历史已记录的账再记一遍；「刚才那杯咖啡记到前天」稳定生效。
  • 主动提醒真正送达：预算临界 / 异常消费 / 储蓄偏离 → 聊天、系统通知与提醒中心；后台每日 20:00 检查，可逐类关闭。
  • 储蓄进度：确认月收入与储蓄目标后，「存钱进度」由本地确定性计算：预计结余、缺口与剩余天数。
  • 隐私细节：通知锁屏不显示金额；提醒与记忆数据排除系统备份与设备迁移。
  • 质量：372 项 JVM 单测 + 4 套本地评测基准全部通过，GitHub Actions 持续集成。
